Potato Plant Disease Detection Using VGG16

📌 Project Overview

This project uses deep learning and the VGG16 model to detect potato plant diseases from leaf images. It classifies leaves into three categories: Healthy, Early Blight, and Late Blight.

🎯 Objectives

- Detect potato leaf diseases using image classification.
- Apply transfer learning with the VGG16 model.
- Support early disease identification and crop management.

🛠️ Technologies Used

- Python
- TensorFlow and Keras
- VGG16 (Transfer Learning)
- OpenCV, NumPy, Matplotlib
- Google Colab
- Kaggle Dataset

⚙️ Methodology

1. Collect potato leaf images from the dataset.
2. Preprocess and resize images to 224 × 224 pixels.
3. Apply data augmentation to training images.
4. Train and fine-tune the VGG16 model.
5. Evaluate the model using classification metrics.
6. Predict the disease category from a leaf image.

📂 Dataset

The project report describes 2,152 images across three classes:

- Healthy
- Early Blight
- Late Blight

📊 Results

The project report records a peak validation accuracy of **99.53%** during training. Performance on new, real-world images may vary.

🌱 Future Scope

- Develop a web or mobile application.
- Test the model on real-world field images.
- Extend the system to support more crops and diseases.
